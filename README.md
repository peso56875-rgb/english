# Introduction to Mechatronics (MEC 141) — Question Bank & Challenge Hub

موقع تفاعلي متكامل لمراجعة واختبار مادة **مقدمة في هندسة الميكاترونكس (Introduction to Mechatronics — MEC 141)** (كلية الهندسة — جامعة الدلتا للعلوم والتكنولوجيا) مبني باستخدام HTML5, CSS3, JavaScript فقط.

---

## 🌟 مميزات المنصة

- **بنك أسئلة شامل (133 عنصراً كاملاً)**:
  - **80 سؤال اختياري (Part I: Multiple Choice)** مقسمة على 8 مجموعات تدريسية (Sets A–H).
  - **30 سؤال أكمل الفراغات (Part II: Fill in the Blanks)** مع إجابات الـ Answer Key النموذجية.
  - **23 سؤال رسومات ومخططات تطبيقية (Part III: Drawing & Schematics)** مع قائمة المكونات، العلاقات الرياضية، ومخططات الدوائر وتوصيلات Arduino.
- **نظام اختبار عشوائي ذكي (Quiz Mode)**:
  - عشوائية كاملة لترتيب الأسئلة والخيارات الأربعة (A, B, C, D) في كل محاولة.
  - إمكانية تحديد موضوع معين أو كل الموضوعات معاً.
  - تحديد عدد الأسئلة (10 أو 20 أو 50 أو الكل).
  - تصحيح فوري بتأثيرات صوتية وبصرية (Web Audio API).
  - اختصارات الكيبورد (1, 2, 3, 4 للاختيار و Enter للمتابعة).
  - شاشة نتائج مفصلة ومراجعة الأخطاء فقط مع حفظ أعلى نتيجة في `localStorage`.
- **بنك المراجعة الشامل (Study Bank)**:
  - **هايلايت أخضر واضح ومميز (`✓ الإجابة الصحيحة`)** على كل إجابة صحيحة في أسئلة الـ MCQ.
  - بطاقات مخصصة لأسئلة أكمل الفراغات مع الإجابة النموذجية والجملة المكتملة.
  - بطاقات هندسية للرسومات والمخططات التوضيحية وتوصيل الحساسات.
  - أزرار تصفية سريعة (الكل 133 / اختياري 80 / أكمل 30 / رسومات 23).
  - محرك بحث فوري لكافة المصطلحات والحساسات.
- **تصميم هندسي عصري (Mechatronics Cyber Dark Theme)**:
  - متجاوب بالكامل مع كافة الشاشات (كمبيوتر، تابلت، وموبايل).

---

## 📁 هيكل المشروع

- `index.html` — الواجهة الرئيسية الدلالية.
- `css/style.css` — التنسيقات ونظام التصميم وحالات الإجابات والهايلايت.
- `js/questions.js` — بنك أسئلة الميكاترونكس الكامل والمخططات والملاحظات.
- `js/app.js` — محرك الاختبار والمراجعة والبحث والفلترة ومؤثرات الصوت.
- `MEC141_QuestionBank_Students_DECRYPTED.pdf` — ملف بنك الأسئلة المصدري.
