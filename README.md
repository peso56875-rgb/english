# Data Networks — Challenge & Study Mode

موقع تفاعلي لمراجعة مادة **Data Networking** مبني باستخدام HTML وCSS وJavaScript فقط. يجمع بين اختبار عشوائي بتصحيح فوري ووضع مراجعة يعرض الإجابات الصحيحة بوضوح.

## الهدف

تجميع محتوى ملفات المراجعة المرفوعة في بنك واحد منظم يساعد الطالب على التدريب والمراجعة السريعة قبل الامتحان، مع تغطية IP Addressing وOSI وEthernet وWireless LAN ووسائط النقل والسيناريوهات العملية.

## المزايا المكتملة

- بنك مكوّن من **121 سؤال اختيار من متعدد** مستخلص ومراجع من ملفات Data Networking المرفوعة.
- ستة موضوعات قابلة للفلترة:
  - IP Addressing
  - OSI & Addressing
  - Ethernet
  - Wireless LAN
  - Transmission Media
  - Protocols & Scenarios
- اختيار 10 أو 20 أو 50 سؤالًا أو البنك كاملًا.
- ترتيب عشوائي للأسئلة والاختيارات في كل محاولة.
- تصحيح فوري بالأخضر والأحمر، ثم انتقال تلقائي للسؤال التالي.
- نتيجة مباشرة، شريط تقدم، أفضل نتيجة محفوظة، ومراجعة أخطاء المحاولة.
- **وضع مراجعة مستقل** يعرض السؤال والاختيارات ويضع هايلايت أخضر على الإجابة الصحيحة.
- بحث مباشر داخل المراجعة وفلترة حسب الموضوع.
- ملاحظات تفسيرية للأسئلة التي تحتاج حسابًا أو توضيحًا.
- دعم الأرقام 1–4 للاختيار وEnter للمتابعة.
- تصميم متجاوب للكمبيوتر والهاتف.

## المسارات الوظيفية

- `/index.html` — التطبيق الرئيسي: البداية، الاختبار، المراجعة، والنتائج.
- `/index.html#review` — فتح وضع المراجعة مباشرة.
- لا توجد معاملات URL أخرى مطلوبة.

## الملفات الرئيسية

- `index.html` — واجهة التطبيق الدلالية.
- `css/style.css` — التصميم والتجاوب وحالات الإجابات.
- `js/questions.js` — بنك أسئلة Data Networks والإجابات والملاحظات.
- `js/app.js` — العشوائية، التصحيح، النتائج، البحث، والفلترة.
- `source/networking/` — ملفات PDF المصدر المرفوعة.

## البيانات والتخزين

- بنك الأسئلة مخزّن محليًا داخل `js/questions.js`.
- أفضل نتيجة محفوظة في `localStorage` بالمفتاح `data-networks-best`.
- لا توجد قاعدة بيانات أو API أو بيانات شخصية.

## روابط عامة

- رابط الإنتاج: غير منشور حتى الآن.
- API endpoints: لا يوجد؛ المشروع Frontend فقط.

## غير منفذ حاليًا

- حسابات مستخدمين أو مزامنة بين الأجهزة.
- لوحة تحكم لتعديل بنك الأسئلة.
- مؤقت امتحان اختياري.
- أسئلة مقالية بتقييم تلقائي.

## خطوات مقترحة

1. إضافة وضع امتحان رسمي بدون إظهار التصحيح حتى النهاية.
2. إضافة مؤقت اختياري وسجل للمحاولات.
3. إضافة صور ورسومات أسئلة NAT وWireless Frame عند توفر نسخ واضحة.
4. مراجعة أي صياغات أو أخطاء مطبعية أصلية مع مدرس المادة.

## التشغيل

افتح `index.html` في متصفح حديث، أو شغّل المشروع عبر أي خادم ملفات ثابت.
